# Kitchen studio UI review

Review branch: `ui/glass-workspace`. This change is for review and does not update the production branch.

The studio now has a shared green-and-stone design system, a dedicated project dashboard shell, an illustrated staff sign-in screen, and refined editor controls. Glass effects are limited to floating controls and headers so forms remain readable. The dashboard and editor no longer share the same outer workspace layout.

## Included

- Responsive project navigation, search, recently updated/name sorting, and clearer project actions.
- Existing create, open, import, rename, duplicate, recover, Trash and restore workflows.
- Staff login, password visibility control, light/dark appearance and accessible control labels.
- Existing 3D, room planning, cabinet selection, costing and fabrication screens with updated spacing and surfaces.
- Decorative kitchen artwork. Project cards deliberately do not invent rendered previews of saved designs.

## Validation

- `npm test`: 118 tests passed.
- `npm run build`: successful. Vite still reports its existing large-bundle advisory.
- Local browser checks with sample API responses: password visibility, project search and sorting, rename, Trash and restore, light/dark appearance, open editor, quote navigation, create project, and layout overflow at 320, 390, 768, 1024 and 1440 px.
- Live cloud authentication, project persistence and production integrations were not exercised. Their application logic and API contracts remain unchanged.

## Deployment boundary

`vercel.json` disables Git-triggered deployment specifically for `ui/glass-workspace`. Other branches retain their existing behavior. No production deployment, merge or database migration is part of this review.

To run locally, use the existing environment setup and `npm ci`, then `npm run dev`. The normal staff sign-in requirement remains. The screenshots were generated by a separate local browser fixture; there is no demo-auth bypass in the application.
